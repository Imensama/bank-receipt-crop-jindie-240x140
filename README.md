# 银行回单裁切 → 金蝶 240 × 140 mm

把中行、邮储、建行导出的带框电子回单，按 **600 DPI 截图**，一张回单放一页，
自动排版到金蝶 240 × 140 mm 凭证纸上。适合财务每月批量打印。

- 600 DPI 截图，页面里只有一张回单图片
- 没有文字层、没有隐藏内容；不提取文字、不重新打字、不重画表格
- 自动拆一页多张：中行 2 张、建行 3 张、邮储 1 张
- 默认只缩不放：邮储/建行 100%，中行 96%
- 本地运行，不联网、不上传

## 下载

从右侧 **Releases** 下载 `bank-receipt-crop-v2-win64.zip`。

## 使用

1. 解压整个文件夹，保持 `回单裁切v2.exe` 和 `_internal` 在一起。
2. 把一个或多个 PDF 拖到 `回单裁切v2.exe` 上。
3. 在**第一个 PDF 所在文件夹**里生成 `回单_金蝶纸_240x140.pdf`。
4. 打印：纸张 240 × 140 mm、横向、实际大小 100%、关闭双面。

不需要安装 Python。

## 尺寸说明

| 银行 | 输出比例 | 说明 |
| --- | --- | --- |
| 邮储 | 100% | 原尺寸 |
| 建行 | 100% | 原尺寸；回单本身较矮，所以上下留白多 |
| 中行 | 96% | 回单高 137 mm，金蝶纸只有 140 mm，加 4 mm 白边放不下；只能略缩 |

想放大填满纸张，用命令行加 `--fill`。放大后就不是原尺寸了。

## 从源码运行

需要 Python 3.10+。

```bash
pip install -r requirements.txt
python receipt_crop.py 邮储.pdf 中行.pdf 建行.pdf
```

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `inputs` | 一个或多个回单 PDF | 必填 |
| `-o, --output` | 输出 PDF | 第一个 PDF 同目录的 `回单_金蝶纸_240x140.pdf` |
| `--dpi` | 截图分辨率 | `600` |
| `--margin MM` | 四周白边（mm） | `4` |
| `--fill` | 允许放大填满纸张 | 关闭（只缩不放） |
| `-q, --quiet` | 不打印明细 | 关闭 |

Windows 上也可以把 PDF 拖到 `run.bat` 上运行；首次运行会自动安装依赖。

## 原理

1. 用表格行、文字、印章图片把一页 PDF 聚成若干“回单块”。
2. 每一块按 600 DPI 渲染成图片，缩放后居中放到 240 × 140 mm 页面。
3. 页面只有这一张图片，没有源 PDF 的其余内容。

## 已知限制

- 只适用于带框的电子回单；纯扫描图片、整页旋转 90° 的 PDF 识别不到。
- 输出页没有文字层，不能复制/搜索；这是为了只保留可见内容。
- 目前验证过中行、邮储、建行；其他银行可以先试，版式特殊再发样本。

## 合规提醒

- 输入 PDF 只读，程序不会修改原件；银行原始电子回单请务必留档。
- 输出是派生打印件，不是银行原始电子文件；税务/审计是否接受，按你们当地要求确认。
- 仓库只包含代码，不包含任何真实回单、账号或公司数据。
